# Наберёшь?

Корпоративные видеозвонки: Telegram/API → SQLite → конференция → P2P WebRTC. Express, Vue и Socket.IO сохранены.

Запуск: npm ci, затем npm start. Node.js 20 рекомендуется для исходной зависимости better-sqlite3 9.x. Порт по умолчанию 824.

Обязательные настройки: BOT_API_SECRET; CORS_ORIGIN — адрес приложения. DB_PATH указывает на существующую SQLite базу; новый путь по умолчанию ./data/naberesh.db. Перед обновлением задайте DB_PATH на вашу прежнюю базу или перенесите её при остановленном приложении вместе с WAL/SHM. Создание конференции: POST /api/createConference с прежней авторизацией и telegramUserId.

TURN: TURN_HOST, TURN_SECRET (совпадает с coturn), TURN_URLS через запятую, TURN_TTL в секундах (по умолчанию сутки). Без секрета используются STUN либо прежние TURN_URL_UDP/TURN_URL_TCP, TURN_USERNAME, TURN_PASSWORD. Credentials выдаются через /ice-config.js без кэша. Постоянные пароли больше не записываются в файлы и логи.

coturn подключается отдельно: конфиг /etc/coturn/turnserver.conf, запуск sh entrypoint.sh; TURN_HOST, TURN_SECRET, при необходимости EXTERNAL_IP, TLS_CERT и TLS_KEY. Откройте 3478 UDP/TCP, relay 49160–49200 UDP, 5349 TCP при TLS. Объявляйте turns URL только с настроенным сертификатом. Docker-топология приложения сохранена; имя сервиса и контейнера обновлено. Перед пересозданием контейнера сохраните БД: исходный compose не содержит постоянного тома.

Сервис требует HTTPS для камеры вне localhost. Медиа остаются mesh: нагрузка растёт с количеством участников. TURN необходимо проверить из внешней сети. Страница, открытая дольше TURN_TTL до входа, требует обновления для свежих credentials.

Метаданные домена в views/head.ejs необходимо сверить с адресом развёртывания. Исходные оформление и значки сохранены; старые рекламные снимки удалены. Service worker обновляет старый кэш и использует сеть: офлайн-звонки не поддерживаются.

Для локального доступа только с этого компьютера задайте HOST=127.0.0.1. Без HOST поведение сервера не меняется.

Проверки: npm test. Локально подтверждены запуск на Node.js 20.20.2, API/SQLite, изоляция WebSocket-конференций, видеосвязь двух участников и выход. Звук, чат, демонстрация экрана и внешний TURN требуют дополнительной проверки.
